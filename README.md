# ♞ Deep Chess — AI Engine v2.0

A local chess web app with a **deep neural network AI brain** and a premium browser UI.

The browser renders a fully interactive chess board and communicates with the Python server over a local HTTP API. The Python backend handles all chess rules, game state, premoves, and AI search in background threads — keeping the UI always responsive while the engine thinks.

## 🤖 Engine Levels

All levels use the opening book first (if available), then the neural policy (if model is trained), then minimax search.

| Level | Name | Search Depth | Behaviour |
|---|---|---|---|
| 1 | Easy | 2-ply + quiescence | 15% blunder rate — feels human |
| 2 | Medium | 4-ply + quiescence | Solid tactical play |
| 3 | Hard | 6-ply + quiescence | Very strong, always picks best move |

> **Tip:** In AI mode, White = human, Black = engine. In Friend mode, both sides are human.

## 🏋️ Train the Neural Network

The CNN model uses an AlphaZero-style architecture with residual blocks, trained on master PGN games.

```bash
# Quick test (2 min, CPU)
.venv/bin/python training/train_neural_policy.py --profile mini --max-games 1000 --epochs 3

# Level 1 model (20-30 min, CPU)
.venv/bin/python training/train_neural_policy.py --profile level1 --max-games 20000 --epochs 8

# Level 2 model (1-2 hrs, CPU or M-series Mac)
.venv/bin/python training/train_neural_policy.py --profile level2 --max-games 80000 --epochs 10

# Level 3 model (GPU recommended)
.venv/bin/python training/train_neural_policy.py --profile level3 --max-games 200000 --epochs 20
```

The trained model is saved to `data/neural_policy.keras` and loaded automatically at runtime.

### Training Profiles

| Profile | Res Blocks | Filters | ELO estimate |
|---|---|---|---|
| mini | 2 | 32 | ~800 |
| level1 | 4 | 64 | ~1200 |
| level2 | 8 | 128 | ~1600 |
| level3 | 15 | 256 | ~2000+ |

## 🔌 API Endpoints

| Method | Path | Description |
|---|---|---|
| GET | `/api/state` | Full game state snapshot |

## 📝 Notes

- The engine **never uses cloud/internet** — all computation is local.
- Transposition table is cleared between games automatically.
- The neural model improves significantly with more training data — `level2` profile is the sweet spot for strength vs. training time.
- The move log tracks both sides in standard UCI notation with piece icons.
